# Calculator 🧮

A simple, responsive calculator built after learning DOM Manipulation — compatible with all devices.

🔗 **Live Demo:** [roankraj.github.io/Calculator](https://roankraj.github.io/Calculator/)

## ✨ Features

- **Basic Operations** – Addition, subtraction, multiplication, division, and modulo (%)
- **Advanced Functions** – Square (x²), inverse (1/x), square root (√), and sign toggle (+/-)
- **Keyboard Support** – Full keyboard input for numbers, operators, Enter/Equals, and Backspace
- **Visual Feedback** – Buttons highlight briefly when pressed (via click or keyboard)
- **Clear & Clear Entry** – Reset the current entry or the entire calculation
- **Expression History** – Shows the full expression above the result
- **Responsive Design** – Works smoothly across desktop and mobile devices

## 🛠️ Built With

- **HTML5** – Calculator layout and button grid
- **CSS3** – Responsive, adaptive styling
- **Vanilla JavaScript** – DOM manipulation, event handling, and expression evaluation

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/roankraj/Calculator.git
   ```
2. Open `index.html` in your browser

## ⌨️ Keyboard Shortcuts

| Key                 | Action                |
| ------------------- | --------------------- |
| `0`-`9`             | Enter digits          |
| `+` `-` `*` `/` `%` | Operators             |
| `.`                 | Decimal point         |
| `Enter` / `=`       | Calculate result      |
| `Backspace`         | Delete last character |

## 📌 Purpose

This project was built as part of my learning journey to practice DOM manipulation, event listeners, and handling both mouse and keyboard input in JavaScript.
